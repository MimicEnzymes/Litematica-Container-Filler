Litematica Container Filler 是一个围绕 Litematica 投影原理图设计的客户端辅助模组，用于读取投影中的容器内容，并把现实世界中的容器按槽位填充到对应状态。

它不是简单复制容器，而是尽量按投影要求计算缺失、多余、错误物品、锁槽状态、容器过滤、数据同步和背包物流，让大型分类、仓储、合成站、地图画装盒等工程更容易批量处理。

## 主要功能

- **投影容器填充**：根据 Litematica 原理图中的容器 NBT，按槽位填充现实容器。
- **单次填充和填充工作**：单次填充处理准星指向的容器；填充工作会在范围内持续扫描、排队并填充可处理容器。
- **范围填充半径**：可配置扫描半径，支持玩家在容器堆附近移动时持续寻找任务。
- **材料列表集成**：在 Litematica 材料列表中补充容器物品统计，并支持未加载原理图时直接解析原理图文件。
- **合成器支持**：支持合成器槽位锁定状态；材料不足时仍会优先处理需要锁定的槽位。
- **材料替换**：可把投影要求的物品替换为其他物品；目标为 `minecraft:air` 时视为忽略该材料，不需要填充。
- **空投影容器清理**：可把投影中本应为空、现实中却有物品的容器清空，用于清炉灰等场景。该功能可能破坏机器，请谨慎开启。
- **大箱子与 Carpet 大木桶**：支持双箱整体处理；Carpet largeBarrels 支持关、开、自动三种模式。
- **容器过滤**：支持白名单、黑名单和应用范围选择，可限制投影填充、工具或两者共同使用的容器类型。
- **自适应容器识别**：除原版常见容器外，会尝试识别带方块实体和常见容器命名的非原版容器。

## 数据同步

- **本地缓存**：打开过的容器会记录真实内容，用于后续高亮和填充判断。
- **Servux / MiniHUD 数据**：可接收兼容数据源的容器数据，减少必须打开容器的情况。
- **OP 主动查询**：拥有权限时可主动获取容器 NBT，加快大范围同步。
- **未知状态处理**：没有真实数据时会按未知状态渲染，避免把未同步容器误判为已填充或未填充。

## 背包与潜影盒物流

- **QuickShulker 支持**：可调用 QuickShulker 打开背包中的潜影盒取货。
- **模拟点击模式**：为其他快捷潜影盒类模组预留，通过模拟右键打开背包中的盒子。
- **TakeItOut 支持**：可自动检测服务端 TakeItOut 协议，在不安装客户端 TakeItOut 的情况下尝试从潜影盒取货。
- **有序存放物品**：替代旧的自动腾空间逻辑。缺空间时优先把物品放回来源潜影盒或已有同类物品的潜影盒，再使用其他合适盒子。
- **慢速点击包模式**：面向插件服和反作弊环境，可限制自动容器操作每 tick 发送的点击包数量；默认关闭。

## 容器工具

容器工具是独立于投影填充的准星工具。启用工具后，看向容器并按触发键即可执行当前工具。

- **清空容器**：清空准星指向的容器，可选择把物品放入背包或直接丢出。
- **填满容器**：用背包中明确的一种物品类型填满目标容器，适合临时合成站。
- **同步容器**：第一次读取模板容器，之后把同类型目标容器同步为模板布局；可配置是否允许使用快捷潜影盒补货。
- **容器收纳**：把目标容器内容收进背包中的潜影盒，优先放入已有相同物品的盒子，再使用其他有空间的盒子。
- **工具 HUD**：可选显示当前工具、执行键、切换键和关闭键；HUD 默认关闭，可在渲染编辑器中配置样式、透明度、缩放、位置和动画帧率。

## 高亮与渲染

- **状态高亮**：支持未填充、未满、溢出、错误、完成、未知数据、未放置等状态。
- **任务标记**：正在填充、排队等待、缺少材料可以显示独立的 3D 标记。
- **隐藏完成容器**：可隐藏已满足投影要求的容器，减少视觉干扰和渲染压力。
- **透视高亮**：可让容器状态隔墙可见。
- **渲染编辑器**：提供单独界面预览并配置高亮、标记、HUD 的颜色、大小、透明度、动画 FPS 和位置。
- **性能开关**：高亮状态、任务标记、HUD、动画帧率和最大排队标记数量都可以单独控制。

## 状态保护与超时处理

旧版本中曾出现过“操作超时，自动重置状态”弹出后自动操作卡住，只能完全重启客户端恢复的情况。当前版本已经对这些路径做了防护：

- 操作超时会清空当前任务、任务队列、失败缓存和黑名单。
- 超时和紧急停止会关闭正在打开的容器界面。
- 超时和紧急停止会清空慢速点击包缓冲，避免旧点击包在后续操作中继续发送。
- 离开世界、切换维度、切换玩家会话、死亡重生等状态变化可自动关闭填充工作。
- 关闭“启用模组”会停止状态机并重置点击包限速器。

如果仍然复现卡死，优先检查是否启用了慢速点击包模式、隐藏 GUI、快捷潜影盒模拟点击或第三方服务器插件，因为这些路径最容易受到服务器响应和客户端界面状态影响。

## 快捷键

- **打开配置**：默认 `L + C`。
- **单次填充**：默认 `V`。
- **填充工作**：在配置项中使用布尔开关加热键的形式设置。
- **执行容器工具**：需要用户自行绑定。
- **切换容器工具**：需要用户自行绑定。
- **关闭所有工具模式**：需要用户自行绑定。
