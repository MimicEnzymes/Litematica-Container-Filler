一个围绕投影原理图（Litematica）设计的容器填充辅助模组，用于将原理图中的容器内容还原到实际世界中。

------------------------------------------------------------------------

### 核心功能

-   **基于投影的容器填充**
    根据原理图中记录的容器内容，对实际容器进行逐槽位填充，而不是简单同步或复制。

-   **填充模式**
    支持类似投影打印的操作方式：

    -   准星模式（针对单个容器）
    -   范围模式（批量处理区域内容器）
    -   按住触发 / 持续填充

-   **自动生成材料列表**
    可生成当前投影所需的容器填充材料列表，方便整理与准备资源。

-   **材料替换（配置支持）**
    支持在配置界面中自定义替换规则，例如：

        minecraft:stick#name1 -> minecraft:glass#name2

    可用于统一材料或进行替代填充。

-   **可视化辅助（配合 Tech Util Mod）**
    可显示容器中"目标应放入的物品"，并同步体现替换规则。

-   **背包满处理选项**
    提供开关：

    -   背包满时停止操作
    -   或将多余物品丢弃为掉落物

------------------------------------------------------------------------

### 适用场景

该模组适用于需要**精确控制容器内容结构**的场景，例如：

-   **单物品 / 多物品分类器搭建**
-   **编码全物品仓库（filter / 槽位预填）**
-   **大规模仓储系统复制或搬迁**
-   **高速熔炉阵列清理（如掏炉灰）**
-   **其他需要批量设置容器内容的红石结构**

------------------------------------------------------------------------
