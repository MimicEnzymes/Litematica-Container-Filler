## 简介

Litematica Container Filler 是一个 Fabric 客户端模组，用来读取 Litematica 投影中的容器内容，并把现实世界中的对应容器填充到投影要求的状态。

它主要服务于大型仓储、分类、合成站、地图画装盒、自动合成器和大量容器堆的施工场景。模组不会只做简单复制，而是会根据投影要求、真实容器缓存、背包物品、潜影盒物流、容器过滤、物品替换、锁槽状态和渲染设置综合判断每个容器的状态。


## 快速开始

1. 安装 Fabric Loader、Fabric API、MaLiLib 和 Litematica。
2. 将本模组放入 `mods` 文件夹。
3. 进入游戏后按默认热键 `L + C` 打开配置界面，也可以从 Mod Menu 或 MaLiLib 配置下拉列表进入。
4. 对准投影中的目标容器，按默认热键 `V` 执行一次填充。
5. 如果要连续处理附近容器，在配置中的 `填充工作 / Work State` 一行设置开关和热键。

## 核心功能

### 投影容器填充

- 按 Litematica 投影里的容器 NBT 和槽位内容填充现实容器。
- 支持单次填充和统一的填充工作状态；填充工作会按范围半径扫描、排队并持续处理可填充容器。
- 支持自动合成器槽位锁定，材料不足时仍会优先完成需要锁槽的操作。
- 支持双箱整体处理。
- 支持 Carpet `largeBarrels` 大木桶规则，但需要在配置中手动开启；当前只有 `关 / 开` 两个模式，没有自动模式。
- `范围填充半径` 为 `0` 时表示不限制半径。
- `操作延迟` 和 `安全延迟` 可用来降低服务器、插件或反作弊环境下的误判风险。
- `填充状态保护` 可在离开世界、切换维度、死亡重生、进入或退出游戏等状态变化时自动关闭填充工作。

### 数据同步与真实容器缓存

- 打开过的容器会记录真实内容，用于后续高亮和填充判断。
- 可以接收 Servux 或兼容协议提供的容器数据。
- 会尝试读取 MiniHUD 容器预览缓存，减少重复打开容器的需求。
- 拥有权限时可使用 OP NBT 查询加快真实容器数据同步。
- 未拿到真实数据时会显示为未知数据状态，避免把未同步容器误判为已完成。
- 数据同步、容器高亮和主要布尔开关均支持 `开关 + 热键` 的配置形式。

### 物品替换

物品替换会作用于投影填充和容器材料列表，不只是隐藏材料列表条目。

- 支持全局物品替换规则。
- 支持当前原理图专用替换规则。
- 同一物品同时匹配全局规则和原理图规则时，原理图规则优先。
- 可视化替换窗口支持精确物品组件，包括自定义名称、附魔和数据组件。
- 手写规则支持 `原物品ID->目标物品ID`，例如 `minecraft:stone->minecraft:cobblestone`。
- 手写规则支持自定义名称匹配，例如 `minecraft:paper#slot1->minecraft:iron_ingot`。
- 目标写为 `minecraft:air` 时，该物品会在填充中被忽略，不会被填充。
- 材料列表中会显示被替换物品的标记，并提供清空当前物品替换项的入口。

### 材料列表集成

模组会在 Litematica 材料列表界面增加容器相关入口：

- `方块`：只显示普通建筑材料。
- `容器`：只显示投影容器内需要的物品。
- `全部`：同时显示建筑方块和容器物品。
- 可以从材料列表直接打开物品替换窗口。
- 可以清空当前原理图的替换项。
- 可以使用容器工具从准星指向的容器中收集材料列表缺失物品。

### 背包与潜影盒物流

- 支持从玩家背包里的潜影盒提取需要的物品。
- QuickShulker 可用时优先使用 QuickShulker 打开潜影盒。
- 模拟右键模式用于兼容其他类似快捷潜影盒的模组，但具体可用性取决于目标模组是否监听对应操作。
- 支持 TakeItOut 协议；服务端安装 TakeItOut 时，客户端不安装 TakeItOut 也可以尝试请求潜影盒中的物品。
- 支持按潜影盒内容匹配不同颜色但内容相同的潜影盒。
- `有序存放物品` 用于替代旧的自动腾包逻辑：需要腾出空间或归还物品时，优先放回来源潜影盒或已有同类物品的潜影盒。
- `慢速点击包` 默认关闭，适合插件服或反作弊较严格的服务器，用来限制自动容器操作每 tick 发送的点击包数量。

## 容器工具

容器工具独立于投影填充，适合临时整理、同步、清空和收集物品。工具需要先启用，再对准容器按执行热键。

| 工具 | 用途 |
| --- | --- |
| 清空容器 | 清空准星指向的容器，输出可选丢出、放入背包、先放背包再丢出。 |
| 填满容器 | 从背包选择明确物品，把准星指向的容器填满；可设置自动装填阈值。 |
| 同步容器 | 第一次读取模板容器，之后把目标容器同步为模板布局；可选允许使用快捷潜影盒补货。 |
| 容器收纳 | 将目标容器里的物品收进背包中的潜影盒，优先塞入已有相同物品的盒子。 |
| 收集材料 | 从目标容器中收集 Litematica 材料列表缺失物品，可设置是否保留少量物品和是否自动关闭 GUI。 |

工具相关功能：

- 支持切换下一个工具、切换上一个工具、关闭所有工具模式。
- 支持长按执行热键重复执行，默认关闭。
- 同一容器重复执行有独立冷却配置，避免站在合成站前持续操作时刷爆状态机。
- 工具 HUD 默认关闭；启用后会显示当前工具、执行键、切换键和关闭键。
- 工具 HUD 自带切换动画，HUD 关闭时会使用轻量纯文本提示。
- 工具 HUD 的边框、样式、透明度、平滑度、大小、图标大小、位置和帧率上限都可配置。

## 高亮与渲染

容器高亮用于判断现实容器与投影要求是否一致。当前渲染不是旧版线框，而是半透明体积、顶部标记片和任务 3D 标记的组合。

支持的状态包括：

- 未填充：投影需要物品，现实容器还没有对应物品。
- 部分填充：已有部分所需物品，但数量、槽位或锁槽状态还没有完全满足。
- 已满足：物品、数量、槽位和相关状态符合投影要求。
- 多余：现实容器中存在超过投影需求的物品。
- 错误物品：现实容器中存在投影不需要的错误物品。
- 未知数据：还没有拿到真实容器数据。
- 未放置容器：投影中需要处理的容器在现实中还没有放置。
- 手动已完成：玩家手动标记为已完成，填充会跳过。
- 手动需填充：玩家手动标记为需要填充，会保持高亮并参与填充。

任务标记包括：

- 正在填充：容器上方的动态向下箭头。
- 排队等待：容器上方的等待动画。
- 缺少材料：短暂提示缺材料状态。

渲染相关设置：

- 容器高亮、透视高亮、同步投影渲染层、未放置容器高亮、空投影容器高亮都可单独开关。
- 每个状态、玻璃体、顶部标记片、填充标记、排队标记、缺材料标记都可单独开关。
- 高亮颜色、透明度、顶部标记片大小、任务标记大小、任务标记停留时间、动画 FPS 上限和最大排队标记数量都可配置。
- 默认关闭高亮透视。
- 默认高亮渲染半径为 `0`。
- 渲染编辑器可以预览并调整高亮、任务标记和工具 HUD。

> [!NOTE]
> 渲染编辑器在很小的窗口、自定义 GUI 缩放、非常规分辨率或非常规窗口比例下可能出现错位或按钮难点的情况。遇到这种情况建议临时使用更大的窗口或默认 GUI 缩放进行配置。

## 容器过滤

容器过滤可以限制哪些容器参与投影填充和工具操作。

- 支持关闭、白名单、黑名单三种模式。
- 可选择过滤规则应用于 `仅投影填充`、`仅容器工具` 或 `投影填充和工具`。
- 默认列表包含箱子、陷阱箱、木桶、潜影盒、合成器、漏斗、发射器、投掷器、熔炉、高炉、烟熏炉和酿造台等常见容器。
- 支持通配符规则，例如 `minecraft:*_shulker_box`。
- 提供可视化容器过滤选择界面。
- 会尝试识别非原版容器：带方块实体的容器、实现物品栏接口的方块，以及 ID 中包含 `chest`、`barrel`、`container`、`storage`、`drawer`、`crate` 等关键词的方块。

## 手动标记

当某些容器因为原理图数据、服务器插件或临时需求无法自动判断时，可以对准容器使用手动标记热键循环状态。手动标记也可以用于不在当前投影范围内的容器。

1. 自动判断。
2. 手动已完成：填充会跳过该容器。
3. 手动需填充：容器会保持高亮并参与填充。

手动标记按维度和坐标记录，并提供清除全部手动标记的触发键。

## 安全与限制

> [!WARNING]
> 在服务器中使用自动容器操作可能被插件或反作弊判定为异常点击、自动整理或自动填充。请根据服务器环境调高操作延迟，必要时开启慢速点击包。

其他限制：

- 多人或服务器环境中，其他玩家、漏斗、插件对容器的改动需要客户端重新拿到真实数据后才能反映到高亮。
- 未安装或不可用的快捷潜影盒类功能会导致相关取货、收纳或容器工具能力降级。
- Carpet 大木桶需要服务端确实启用 `largeBarrels` 规则；没有该规则时请保持关闭，避免槽位偏移和状态错误。
- 总开关 `启用模组` 关闭后，核心状态机、自动填充、工具和渲染相关功能应停止工作。

## 配置分类

配置界面分为以下页签：

- 功能：启用模组、填充工作、范围填充半径、操作延迟、安全延迟、状态保护、Carpet 大木桶、全局物品替换。
- 数据同步：数据同步、OP NBT 查询、慢速点击包和点击包速率。
- 自动化：创造填充、快捷潜影盒取货、潜影盒打开方式、潜影盒内容匹配、有序存放、掉落取出的物品、清空投影为空的现实容器、隐藏投影填充 GUI。
- 容器过滤：过滤模式、应用范围、过滤列表和可视化选择入口。
- 工具：工具启用、工具模式、同步工具取货、长按重复、工具冷却、填满阈值、收集材料设置、清空输出、隐藏工具 GUI、工具 HUD。
- 高亮渲染：容器高亮、透视、渲染半径、投影渲染层同步、各状态开关、任务标记、颜色和性能相关设置。
- 热键：单次填充、打开配置、工具执行、工具切换、关闭工具、手动标记等热键。

## 依赖与兼容

必需：

- Fabric Loader
- Fabric API
- MaLiLib
- Litematica

可选：

- Mod Menu：提供 Mod Menu 配置入口。
- QuickShulker：用于背包潜影盒快速打开和取货。
- Servux 或兼容服务端数据源：用于无需打开容器也能获取真实容器数据。
- MiniHUD：模组会尝试读取其容器预览缓存。
- TakeItOut 服务端协议：用于服务端侧潜影盒取货，客户端不一定需要安装 TakeItOut。
